## Etapa 10d, bot do Telegram (branch `feat/telegram-bot` em `53330a3`, ainda sem merge)

Para testar antes do merge: `git fetch` e `git switch feat/telegram-bot`, depois `npm install` (grammY 1.46.0 novo) e `npm run db:migrate` (migração 0035).

**O que tem:**

- **Meu perfil:** o nome no alto da tela virou botão e abre a janela com os dados do usuário e a seção Telegram (`frontend/src/components/ProfileModal.tsx`). **Gerar código** cria 6 dígitos válidos por 10 minutos. **Abrir o Telegram e vincular** abre `t.me/<bot>?start=<código>` e vincula com um toque. A janela confere a cada 3 s se o vínculo foi feito.
- **Bot** (`backend/src/services/telegram.ts`): `/start` (aviso de IA e instruções; com código, vincula), `/vincular <código>`, `/sair`, e texto livre vai para o mesmo `askAssistant` do chat web, com canal `telegram`. Só conversa privada; grupo é ignorado. Foto e outros tipos recebem "só entendo mensagens de texto".
- **Permissões:** o ctx vem de `resolveTelegramChat` em `backend/src/services/auth.ts`, com o grupo atual do usuário e `actor: 'telegram'`. Usuário inativo ou sem `assistant.use` não conversa.
- **Segurança:** o código fica só como hash SHA-256 em `users.telegram_link_code`. Depois de 5 códigos errados por conversa, o bot espera 10 minutos (`telegram_link_failures`). Vincular e desvincular entram na auditoria com ator `telegram`. O webhook `POST /api/telegram/webhook` só aceita `X-Telegram-Bot-Api-Secret-Token` igual a `TELEGRAM_WEBHOOK_SECRET` (comparação em tempo constante) e responde 200 mesmo com erro interno, para o Telegram não reenviar.
- **Conversa:** as últimas 10 mensagens das 2 horas anteriores ficam em `telegram_messages`; o resto é apagado. Limite de 20 perguntas por minuto por usuário, contado em `ai_usage`.
- **Formatação:** o Markdown do assistente vira HTML do Telegram (`toTelegramHtml`). Endereços como `/ajuda/...` viram link completo com a primeira origem de `ALLOWED_ORIGINS`. Se o Telegram recusar o HTML, manda texto puro.
- **Migração 0035:** colunas `telegram_chat_id` (único), `telegram_link_code` e `telegram_link_expires_at` em `users`; tabelas `telegram_messages` e `telegram_link_failures`.
- **Manual:** `docs/manual/inicio/assistente.md` ganhou "Usar pelo Telegram" e o texto do assistente foi regerado (`npm run manual:ia`).

**Variáveis** (nunca no repositório):

- `TELEGRAM_BOT_TOKEN`: token do @BotFather. O bot é `@arandu_gestao_bot`.
- `TELEGRAM_WEBHOOK_SECRET`: de 16 a 256 letras, números, `_` ou `-`. Valor vazio conta como ausente.
- O usuário já colocou as duas no `backend/.env` do notebook e na Vercel. No `backend/.env` do Windows, ele precisa acrescentar as mesmas. O segredo tem que ser igual ao da Vercel, porque o comando `webhook` cadastra no Telegram o segredo do `.env` local.

**Comandos** (`backend/src/telegramCli.ts`):

```bash
npm run telegram -w backend -- polling                                    # desenvolvimento, sem webhook
npm run telegram -w backend -- webhook https://arandu-gestao.vercel.app   # produção, uma vez depois do deploy
npm run telegram -w backend -- info                                       # webhook atual e último erro
```

**Cuidado:** `polling` apaga o webhook de produção, porque o Telegram não entrega por polling com webhook ativo. Depois de testar local, rode `webhook` de novo. Um token só serve um destino por vez: com o notebook ou o Windows em `polling`, a produção para de receber.

**Testes:**

- `backend/src/tests/telegram.test.ts`, com 12 testes. Os updates são simulados; um transformer do grammY intercepta as chamadas à API, então nenhum teste fala com o Telegram.
- `vitest.config.ts` define token e segredo falsos.
- `playwright.config.ts` passa `TELEGRAM_BOT_TOKEN` e `TELEGRAM_WEBHOOK_SECRET` vazios. O backend do e2e lê o `backend/.env`, e assim o bot real fica desligado no e2e.
- `e2e/profile.spec.ts` cobre a janela Meu perfil.
- No notebook: typecheck e lint sem erro; 289 de 289 testes de API e 113 de 113 e2e (com `TZ=UTC`).

**Limitação da demonstração:** `demo.reset()` restaura `users` da cópia `demo.*` e esvazia as tabelas novas. A cada restauração (00h e 12h), todo vínculo do Telegram volta a "desvinculado". Basta gerar o código de novo.
